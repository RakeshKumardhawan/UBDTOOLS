# Installers Folder

Place your software installer files (`.exe` or `.msi`) in this folder.

Examples:
- `proxkey_driver.exe`
- `nic_digisigner.msi`
- `custom_app_1.exe`
- `custom_app_2.msi`

The E-Vedhika One-Click Deployment Tool will detect and run these installers silently in the background when the **Deploy** button is clicked.
